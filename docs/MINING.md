# Mineração espacial

Protótipo Python sem dependências: mineração de asteroides, capacidade de carga, consumo de energia, dureza de materiais e descarregamento.

Testes: `python -m unittest discover -s tests -v`.

O módulo ainda não está conectado à interface 2D. Futuras melhorias: progressão de ferramentas, economia, mapas e salvamento.
